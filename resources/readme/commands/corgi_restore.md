## corgi restore

Put every repo back to a checkpoint

### Synopsis

Restores each repo to the branch, commit and uncommitted work the checkpoint
recorded. A repo that has uncommitted work now is captured first, under a
safety checkpoint whose name is printed, so nothing is lost.

```
corgi restore <name> [flags]
```

### Examples

```
corgi restore before-referral

corgi restore before-migration --with-db
```

### Options

      --yes       Do not ask before overwriting the current working trees
