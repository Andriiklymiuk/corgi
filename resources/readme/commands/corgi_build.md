## corgi build

Build docker images for docker-capable services, in parallel, without starting anything

### Synopsis

Pre-builds the image of every docker-capable service (a Dockerfile or the
repo's own compose file) so the next corgi run boots from a warm cache.
Respects --services to build a subset. Services without a docker source are
skipped. Exit 1 if any build fails.

```
corgi build [flags]
```

### Options

```
  -h, --help               help for build
      --parallel int       Max concurrent image builds (default 4)
      --services strings   Build only these services (--services api,web)
```
