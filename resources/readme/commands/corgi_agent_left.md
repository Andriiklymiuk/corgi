## corgi agent left

What unattended runs left for a person, ticked off as CI goes green, pull requests merge or you say so

### Synopsis

Each unattended run ends with what is left for a person. corgi keeps those
items and ticks them off itself when it sees them happen: the checks of the
pull request went green, the pull request merged. The rest wait for you.

  corgi agent left
  corgi agent left --done `<id>`     # you did it
  corgi agent left --all --json    # with what closed in the last fortnight

```
corgi agent left [--done <id>] [--all] [flags]
```
