## corgi idea comment

Comment on the page - on highlighted words with --quote, or on the whole page

### Synopsis

  corgi idea comment brewshift "use postgres" --quote "We use sqlite"
  corgi idea comment brewshift "and a waitlist?" --by maria --link https://…
  corgi idea comment brewshift "yes, do that" --reply-to 4      accept a proposal
  corgi idea comment brewshift "see the sketch" --file ./sketch.png

The agent answers on its own when the dashboard runs (corgi agent up) or
when corgi idea watch is on; corgi idea answer `<slug>` does one pass now.

```
corgi idea comment <slug> "<words>" [flags]
```

### Options

```
      --as-agent           the reply is the agent's own answer (a session answering the page): the comment becomes answered
      --by string          your name on the comment (default: $USER)
      --changed            with --as-agent --reply-to: the page was amended for this comment, so it becomes fixed
      --file stringArray   a file to attach (repeatable)
      --heading string     the section the words are under
  -h, --help               help for comment
      --link stringArray   a link to attach (repeatable)
      --prefix string      what comes just before the words, when they are on the page more than once
      --quote string       the words on the page the comment is about
      --reply-to int       reply under this comment instead of starting one
      --suffix string      what comes just after them
```
