## corgi agent watch test

Push one made-up event through the pipeline and print the claude run it would start, without starting it

### Synopsis

Walks a synthesized event the way a webhook's would go: routing to a
workspace, the rules, the seen list, the fix claim and the caps, quiet hours
and the account's limits. Nothing is recorded and no claude runs; the prompt
and argv it would use are printed, so the pipeline can be proven without a
real event.

```
corgi agent watch test <issue.new|issue.comment|pr.comment|pr.review|review.requested|ci.failed> [flags]
```
